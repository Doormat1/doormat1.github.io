💡 Tips:
  • Frequency: Standard A4 note = 440 Hz. Range: 20 Hz - 20,000 Hz
  • Panning: Position each generator in left/center/right stereo field
  • Phase: Adjust phase offset between 0° and 360°
  • Volume: Control individual levels of each generator. Start low!
  • Waveforms: The graphs update as you move the controls, even when stopped. Set two close frequencies (e.g. 440 Hz and 444 Hz) to see beats, or the same frequency 180° apart to see cancellation.
